# @moderanger/core

Pure TypeScript core for [Mode Ranger](https://github.com/antoniovazquezaraujo/moderanger): the song model, the `.mr` parser/serializer and note generation, with no Angular or Tone dependency.

This package is primarily the runtime dependency of [`@moderanger/cli`](https://github.com/antoniovazquezaraujo/moderanger/tree/develop/packages/compiler).
