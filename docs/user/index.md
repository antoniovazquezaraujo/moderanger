# Mode Ranger

**Mode Ranger** es un estudio de armonía: un editor para componer canciones con partes, bloques y arpegios, y un lenguaje de texto — **`.mr`** — que es la representación canónica de cada canción. La interfaz gráfica es una vista guiada del mismo texto.

## Cómo empezar

1. Arranca la app:

   ```sh
   npm ci
   npm start
   ```

2. Crea partes y bloques en la GUI, o pulsa el botón **`.mr`** para editar el texto directamente.
3. Pulsa **Play** para escuchar; **Guardar** descarga la canción como `.mr` y **Cargar** la recupera.
