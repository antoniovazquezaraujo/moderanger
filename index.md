# Mode Ranger

**Mode Ranger** is a harmony studio: an editor to compose songs with parts, blocks and arpeggios, plus a text language — **`.mr`** — that is the canonical representation of every song. The GUI is a guided view of that text.

## Getting started

1. Start the app:

   ```sh
   npm ci
   npm start
   ```

2. Create parts and blocks in the GUI, or press the **`.mr`** button to edit the text directly.
3. Press **Play** to listen; **Save** downloads the song as `.mr` and **Load** restores it.
