Quick guide

Make your first song

Mode Ranger turns small musical ideas into a readable .mr score. Start with one part and grow from there.

  1. 01

    Create a part

    A part is an instrument or voice. Open Parts and use the + to add one.

  2. 02

    Add a block

    Blocks hold the music. Use the block + to create one, then give it a name.

  3. 03

    Write notes

    Click the melody strip or press +. Scroll over a note to change its value or duration.

  4. 04

    Listen and save

    Press Play to hear the result. Save the canonical .mr text with the download button.

Good to know

Text is canonical
The visual editor and the .mr view describe the same song.
Reuse music
Create a block in Blocks and reference it from any part.
Keep it local
Save and load .mr files whenever you want. Nothing leaves your browser.
